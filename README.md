# Omega Stealer: Advanced Operational Data Suite

**Omega** est une suite logicielle conçue pour l'exfiltration de données et l'audit système haute performance. Développé pour les environnements exigeant une efficacité maximale et une furtivité absolue, Omega automatise la collecte et le traitement de données critiques.

Ce projet n'est pas un simple outil ; c'est un framework évolutif, pensé pour les tests d'intrusion avancés et l'analyse de sécurité opérationnelle.

## 🛠 Architecture Technique

Le framework Omega repose sur une architecture multi-couches garantissant stabilité et discrétion :

*   **Loader C++ (Native Execution) :** Un chargeur écrit en C++ gère l'injection et l'exécution, minimisant l'empreinte mémoire.
*   **Payload Python (Dynamic Logic) :** La logique centrale est compilée via Nuitka, transformant le code Python en binaire natif pour contrer l'analyse statique.
*   **Chiffrement AES-256 :** Toutes les données collectées sont chiffrées avant exfiltration, garantissant que les informations transitent en toute sécurité.
*   **Persistance Intelligente :** Mécanismes de persistance furtifs intégrés au registre Windows, garantissant la résilience opérationnelle.

## 🚀 Fonctionnalités Avancées

Omega propose un ensemble d'outils optimisés pour une collecte de données rapide :

- **Credential Harvesting :** Extraction automatisée des identifiants stockés dans les navigateurs, gestionnaires de mots de passe et applications tierces.
- **Session Token Retrieval :** Capture des jetons de session (cookies) pour permettre l'accès aux sessions actives sans authentification.
- **Visual Telemetry :** Capture d'écran haute résolution et télémétrie webcam en temps réel.
- **Evasion Engine :** Détection avancée de machines virtuelles (VM) et de sandboxes pour prévenir toute analyse automatisée.
- **Stealth Exfiltration :** Envoi des données via des canaux chiffrés, optimisés pour contourner les systèmes DLP (Data Loss Prevention) standard.
